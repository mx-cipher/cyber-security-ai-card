## Cyber Security & AI Hub Card
A clean, modern, and minimal profile identity card component built using structured HTML5 and custom CSS3. This project showcases futuristic tech aesthetics, sleek glassmorphism effects, and active status tracking layouts.
## Features

* Futuristic UI Layout: Features a deep obsidian dark background with a structured, glowing glassmorphic card container.
* Visual Enhancements: Includes dynamic glowing profile elements and active status indicators with neon accents.
* Interactive Effects: Features smooth scaling transitions and vibrant border color shifts on hovering the profile node.
* Clean Structure: Uses CSS Grid and Flexbox for absolute center alignment and balanced dashboard metric grids.

## Tech Stack

* HTML5: For core profile elements, status tags, and button navigation structures.
* CSS3: For modern background blur filters, custom glow keyframe animations, and flexible box layout controls.

## What I Learned

* Customizing background layers with radial blur gradients to simulate terminal ambient lightning.
* Implementing micro-animations using custom keyframes to indicate real-time server or system states.
* Structuring multi-column grid components inside minimal card containers without breaking responsive layout bounds.
